# SWYNEX - Data Cleaning & Preparation

## Task 1: Data Cleaning & Preparation

This project was completed as part of Task 1 of my internship at SWYNEX Technologies.

The objective of this task is to clean and prepare a raw dataset for analysis.

## Dataset

The dataset used for this project is a public Cafe Sales dataset.

The dataset contains cafe sales transaction records with the following columns:

- Transaction ID
- Item
- Quantity
- Price Per Unit
- Total Spent
- Payment Method
- Location
- Transaction Date

## Data Quality Issues Identified

The raw dataset contained the following data quality issues:

- Missing values
- ERROR values
- UNKNOWN values
- Inconsistent values
- Missing values in numerical and categorical columns

## Data Cleaning Performed

The dataset was cleaned using Microsoft Excel.

The following steps were performed:

1. Identified missing values.
2. Identified and handled ERROR values.
3. Identified and handled UNKNOWN values.
4. Filled missing values in relevant columns.
5. Checked for duplicate records.
6. Reviewed the dataset for consistency.
7. Saved the cleaned dataset as an Excel file.

## Tool Used

- Microsoft Excel

## Dataset Files

| File | Description |
|---|---|

## Final Result

The raw Cafe Sales dataset was cleaned and prepared for further analysis by handling missing values, ERROR values, UNKNOWN values, and other inconsistent data.

The cleaned dataset is included in this repository for review.

# SWYNEX - Data Cleaning & Preparation

## Task 1: Data Cleaning & Preparation

This project was completed as part of Task 1 of my internship at SWYNEX Technologies.

The objective of this task is to clean and prepare a raw dataset for analysis.

## Dataset

The dataset used for this project is a public Cafe Sales dataset.

The dataset contains cafe sales transaction records with the following columns:

- Transaction ID
- Item
- Quantity
- Price Per Unit
- Total Spent
- Payment Method
- Location
- Transaction Date

## Data Quality Issues Identified

The raw dataset contained the following data quality issues:

- Missing values
- ERROR values
- UNKNOWN values
- Inconsistent values
- Missing values in numerical and categorical columns

## Data Cleaning Performed

The dataset was cleaned using Microsoft Excel.

The following steps were performed:

1. Identified missing values.
2. Identified and handled ERROR values.
3. Identified and handled UNKNOWN values.
4. Filled missing values in relevant columns.
5. Checked for duplicate records.
6. Reviewed the dataset for consistency.
7. Saved the cleaned dataset as an Excel file.

## Tool Used

- Microsoft Excel

## Dataset Files

| File | Description |
|---|---|
| `dirty_cafe_sales.csv` | Original raw dataset |
| `cleaned_cafe_sales.xlsx` | Cleaned dataset |

## Final Result

The raw Cafe Sales dataset was cleaned and prepared for further analysis by handling missing values, ERROR values, UNKNOWN values, and other inconsistent data.

The cleaned dataset is included in this repository for review.

## Task 2 - Exploratory Data Analysis

### Objective

The objective of this task was to perform Exploratory Data Analysis (EDA) on the cleaned café sales dataset from Task 1 and identify important statistics, trends, patterns, and anomalies.

### Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Excel Charts

### Dataset

The cleaned café sales dataset from Task 1 was used for this analysis.

The dataset contains the following columns:

- Transaction ID
- Item
- Quantity
- Price Per Unit
- Total Spent
- Payment Method
- Location
- Transaction Date

### Analysis Performed

#### 1. Basic Statistical Analysis

The following statistics were calculated:

- Total Transactions: 10,000
- Total Revenue: 84,763.5
- Average Transaction Value: 8.48
- Total Quantity Sold: 28,834
- Average Quantity Per Transaction: 2.88
- Average Price Per Unit: 2.79
- Highest Transaction Value: 25
- Lowest Transaction Value: 0

#### 2. Best-Selling Items

A PivotTable was created to analyse the quantity of items sold.

**Key Finding:**  
Juice was the best-selling café item, with 3,373 units sold.

#### 3. Revenue by Item

A PivotTable was created to compare the revenue generated by different café items.

**Key Finding:**  
Salad generated the highest revenue, with total revenue of 16,605.

#### 4. Payment Method Analysis

The number of transactions for each payment method was analysed using a PivotTable.

**Key Finding:**  
Digital Wallet was the most-used known payment method, with 2,291 transactions.

Unknown payment method records were kept separate because they were not valid payment method categories.

#### 5. Location Analysis

Transactions were analysed based on customer location.

**Key Finding:**  
Takeaway was the most-used known location, with 3,022 transactions.

Unknown location records were kept separate from the valid location categories.

#### 6. Revenue Trend Analysis

Monthly revenue was analysed using the transaction date.

A line chart was created to identify revenue trends over time.

**Key Finding:**  
June 2023 recorded the highest monthly revenue, at 7,071.5.

### Anomaly Analysis

Some transactions were found with a **Total Spent value of 0**.

These records may represent unusual or potentially anomalous transactions and should be reviewed before making business decisions.

### Charts Created

The following charts were created using Microsoft Excel:

1. Best-Selling Café Items
2. Revenue by Café Item
3. Customer Payment Methods
4. Transactions by Location
5. Revenue Trend Over Time

### Key Insights

1. Juice was the best-selling café item, with 3,373 units sold.
2. Salad generated the highest revenue, with total revenue of 16,605.
3. Digital Wallet was the most-used known payment method, with 2,291 transactions.
4. Takeaway was the most-used known location, with 3,022 transactions.
5. June 2023 recorded the highest monthly revenue, at 7,071.5.
6. Some transactions had a Total Spent value of 0, which may indicate unusual or potentially anomalous transactions.

### Conclusion

The Exploratory Data Analysis helped identify important sales patterns, customer payment preferences, location-based transaction trends, monthly revenue trends, and possible anomalies in the café sales data.

This task improved my practical understanding of data analysis using Microsoft Excel, PivotTables, formulas, and data visualization.
